Семантический поиск

Семантический поиск — это подход к информационному поиску, при
котором релевантность определяется смысловой близостью запроса
и документа, а не только совпадением слов.

Классический лексический поиск основан на точном совпадении
терминов. Если пользователь введёт «автомобиль», система не найдёт
документы со словом «машина», хотя они семантически близки.
Семантический поиск решает эту проблему.

Основные методы семантического поиска: латентно-семантический
анализ, тематическое моделирование, векторные представления слов,
нейронные эмбеддинги. Все они строят векторное пространство, в
котором близкие по смыслу объекты находятся рядом.

Для оценки качества семантического поиска применяются те же метрики,
что и для лексического: точность, полнота, F-мера, средняя точность.
Однако разметка релевантности для семантического поиска сложнее,
так как требует оценки смысловой близости.

Семантический поиск широко применяется в вопросно-ответных системах,
рекомендательных сервисах, поиске по базе знаний.
