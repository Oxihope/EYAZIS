Инвертированный индекс и его построение

Инвертированный индекс — это структура данных, которая для каждого
термина хранит список документов, в которых этот термин встречается.
Такая структура позволяет быстро находить документы по запросу без
полного перебора всей коллекции.

Построение инвертированного индекса выполняется в несколько этапов.
Сначала каждый документ разбивается на токены, которые затем приводятся
к нормальной форме. После этого для каждого уникального термина
формируется список идентификаторов документов, в которых он встречается.
Дополнительно для каждого термина может храниться частота его вхождения
в каждый документ.

Инвертированный индекс может быть прямым и обратным. Прямой индекс
хранит для каждого документа список его терминов. Обратный индекс
хранит для каждого термина список документов. В поисковых системах
используется именно обратный индекс, так как он позволяет быстро
находить документы по заданному термину.

Для ускорения поиска инвертированный индекс часто дополняется
различными структурами: сжатием списков, сортировкой по частоте,
кэшированием популярных запросов. Современные поисковые системы
используют распределённые инвертированные индексы, размещённые
на множестве серверов.
