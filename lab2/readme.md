# Автоматическое распознавание языка текста

Лабораторная работа №2 по дисциплине «Естественно-языковой интерфейс интеллектуальных систем».

**Вариант 23:** русский и итальянский языки | HTML-документы | методы частотных слов, алфавитный, нейросетевой.

---

## Возможности

- **Три независимых метода распознавания языка:**
  - **Алфавитный** — по преобладанию кириллицы или латиницы (не требует обучения);
  - **Частотных слов** — по косинусной мере между частотными профилями;
  - **Нейросетевой** — MLP-классификатор на символьных 3-граммах.
- **Автоматическая очистка HTML** — удаление тегов, скриптов, навигации, извлечение только текста статьи.
- **Сводная статистика** — точность и среднее время работы каждого метода.
- **Экспорт результатов** — сохранение в CSV, печать через системный диалог.
- **Активные ссылки** — двойной клик по имени файла открывает документ в браузере, ПКМ — контекстное меню.
- **Руководство пользователя** — встроенное, открывается по F1.
