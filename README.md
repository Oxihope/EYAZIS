# ИПС на основе векторной модели

Лабораторная работа №1 по дисциплине «Естественно-языковой интерфейс интеллектуальных систем».

**Вариант 27:** модуль отбора документов | локальная вычислительная сеть | векторная стратегия | русский язык.

---

## Возможности

- **Векторная модель поиска** — TF-IDF + косинусная мера.
- **Автоматическая индексация** — токенизация, лемматизация (pymorphy3), фильтрация стоп-слов и частей речи.
- **Паук** — следит за папкой и вложенными подпапками, автоматически обновляет базу при добавлении, изменении и удалении файлов (`.txt`, `.docx`).
- **Псевдорелевантное расширение запроса (PRF)** — элемент ИИ, улучшающий полноту поиска.
- **9 метрик качества** — Precision, Recall, F1, Accuracy, Error, AP, P@5, P@10, R-Precision.
- **Руководство пользователя** — встроенное, открывается по F1.
