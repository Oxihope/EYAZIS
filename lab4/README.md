# Машинный перевод EN → RU (вариант 7)

Лабораторная работа №4 по дисциплине «Естественно-языковой интерфейс интеллектуальных систем».

**Вариант 7:** англо-русский | медицина + критика изобразительного искусства | прямой пословный перевод.

## Возможности

- **Прямой пословный перевод** английского текста на русский с использованием двуязычного словаря.
- **Загрузка файлов** TXT, DOCX, PDF, HTML, RTF, DOC.
- **Синтаксический анализ английского** через spaCy: токенизация, POS-теги, лемматизация, дерево зависимостей и конституентное дерево.
- **Русская морфология** через pymorphy3: приведение переводов к базовой форме.
- **Частотный список** с переводами и грамматической информацией.
- **Дерево разбора** для выбранного предложения.
- **Редактор словаря** с сохранением в JSON.
- **Экспорт в TXT (UTF-8)** и печать.
- **Справка** по F1.

## Требования

- Python 3.10+
- Windows / Linux / macOS

## Установка

```bash
git clone <repo-url>
cd lab4
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
python -m spacy download en_core_web_sm
```

## Запуск

```bash
python main.py
```

## Быстрый старт

1. Откройте вкладку **«Перевод»**.
2. Загрузите `.txt`/`.docx`/`.pdf` файл или вставьте английский текст вручную.
3. Нажмите **«Перевести»**.
4. Просмотрите результат:
   - вкладка **«Частотный список»** — частотный список с переводами;
   - вкладка **«Дерево разбора»** — конституентное дерево выбранного предложения.
5. Обновите словарь через меню **«Словарь → Редактор словаря»**, если встретились непереведённые слова.
6. Сохраните отчёт: **Ctrl+S**.
